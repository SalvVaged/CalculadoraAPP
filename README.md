
# CalculadoraAPP

Proyecto sencillo de creación de una calculadora basica con dos pantallas en Flutter/Dart


## Autores

- [Ricardo Noriega](https://github.com/SalvVaged)

Para el curso de programación 3


## Instalación

### Necesitas para ejecutarlo
- Un editor: [VS Code](https://code.visualstudio.com/) con la extensión **Flutter**

o
- [Android Studio](https://developer.android.com/studio) con el plugin Flutter

Y verificas si todo esta instalado usando

```bash
  flutter doctor
```
    
## Funciones y ejemplos de uso

- Escribe números con el teclado en pantalla.

- Hace uso de operaciones matemáticas (+, -, ×, ÷).

- Pulsa = para ver el resultado de las operaciones matemáticas

- Usa C para borrar un dígito y CE para borrar todo.

- Pulsa el icono ⓘ de la barra superior para ver ir a la pestaña de información.
